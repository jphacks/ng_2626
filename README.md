# お絵描きアプリ（仮）

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要
### 背景(製品開発のきっかけ、課題等）
初対面の人同士では，会話の最初の一歩を踏み出すことが難しく，言語が異なる海外の人との交流ではなおさらです．
一方で，一緒に何かを作るという非言語的な関わりはその壁を越えるきっかけになりえますが，絵を描くことに苦手意識を持つ人は共同での作品作りに参加しにくいという課題があります．
そこで，絵が苦手な人でも気軽に参加でき，出会いのきっかけとその記録を同時に生み出せるアプリを考えました．

### 製品説明（具体的な製品の説明）
スマホなどのデバイスをタップ・スワイプ・フリック・振るといった直感的な操作で動かし，イラストを作成するアプリです．
複数人で同時に描くことで，その場・その時・その人たちでしか生まれない一枚を作り，一期一会の出会いを目に見える形に残します．
また，描いた絵をもとに自分を知ってもらったり，会話を弾ませたりと，初対面の人同士のアイスブレイクとしても活用できます．

### 特長
#### 1. 直感的な操作で誰でも描ける
タップ・スワイプ・フリック・振るといった直感的な操作だけでイラストを作成でき，絵が苦手な人でも制作に参加しやすくなっています．

#### 2. お題で迷わず描き始められる
思考を介さずに描き始められるお題を用意し，描き始めのハードルを下げます．

#### 3. 署名とタイトルで出会いを形に残す
作品に署名を載せることで，誰と描いたものなのかがわかります．
さらに，形になった思い出にタイトルとして名前を与えることができます．

### 解決出来ること
* 絵が苦手な人でも，作品作りに積極的に参加できる
* 初対面の人同士の会話の一歩目をサポートする
* 非言語的な関わりにより，言語の異なる海外の人とも交流できる
