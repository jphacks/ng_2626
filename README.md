# 『OMOIRO』

[![OMOIROで描いた作品「さんしょくだんご」](https://github.com/user-attachments/assets/05eb2931-262d-4a9c-89cf-6986b9004e87)](https://youtu.be/f-XKaN3TXQE)

## 製品概要
複数人で1台の端末を順番に操作し、1枚の絵を共同制作するプロダクトです。
『OMOIRO』という名前は、「思い出」と「想い」、そして「色」を掛け合わせたものです。参加者一人ひとりの想いを色に込めて重ね合わせ、その日の思い出を1枚の絵として、10年後にも残せる形にすることを目指して開発しました。

### 背景（製品開発のきっかけ、課題等）
私たちのチームは、全員が個人エントリーでJPHACKSに参加し、この場で初めて出会いました。数日間、同じ机を囲んで悩み、笑い合いながら一つのものを作り上げていく時間は、かけがえのないものでした。けれど、JPHACKSが終われば、私たちはそれぞれの日常へと戻っていきます。学年や属性が異なる私たちが、もう一度顔を合わせる機会はきっと多くはありません。
せっかく巡り会えたこの出会いを、このまま思い出の中に埋もれさせてしまうのはもったいない。何か形として残すことはできないだろうか。そんな想いが、このプロダクトの出発点でした。

振り返ってみると、こうした「一期一会の出会い」には、次のような課題があると考えました。

- **出会いの記憶は、時間とともに薄れていく**
  関係がその場限りで終わってしまう出会いほど、共に過ごした時間を思い返すきっかけは失われ、記憶は少しずつ色あせていきます。
- **写真では「一緒に過ごした時間」までは残せない**
  集合写真は「その場にいた」という事実を残してくれます。しかし、そこでどんな言葉を交わし、どんな気持ちで同じ時間を過ごしたのかという、その場の空気感や互いの想いまでは写し取れません。
- **「一緒に作る」ことへのハードルがある**
  誰かと何かを共に作った経験は、記憶に深く刻まれます。ところが、絵を描くことに苦手意識を持つ人は多く、共同での作品作りには気軽に参加しにくいのが現状です。

そこで私たちは、その場に集まった一人ひとりの想いを色に込めて重ね合わせ、出会いの記憶を一枚の絵として残せるアプリを考えました。
誰もがすぐに描き始められるよう、操作はタップやスワイプ、端末を振るといった直感的でシンプルな動作だけに絞っています。絵の上手い下手に関係なく、思うままに手を動かすだけで、その日その場所でしか生まれない一枚が完成します。数年後、この絵を見返したときに、あの日の空気や一緒に過ごした人たちのことを、色とともに思い出せるように。そんな願いを込めて開発しました。

また、言葉を交わさなくても一緒に手を動かせることから、初対面の人同士のアイスブレイクや、会話のきっかけとしても使えるよう想定して設計しています。

### 製品説明（具体的な製品の説明）
『OMOIRO』は、1台のスマートフォンやタブレットを複数人で順番に回しながら、1枚の絵を共同で描き上げるアプリです。
参加者には1人1色が割り当てられ、タップで波紋のような円を、スワイプで線を描いていきます。画面に触れるたびに音が鳴り、端末を振ると描いた線が水彩のようににじんで揺らぎます。一人が描き終えたら「次の人へ」で端末を手渡し、次の人が自分の色で線を重ねていきます。何を描けばいいか迷ったときは、「今の気分を線と形で」のような、正解のない抽象的なお題を表示することもできます。

全員が描き終えたら「完成」を押し、参加者一人ひとりが作品の上に自分の色で署名を書き込みます。寄せ書きのように名前が添えられた作品にタイトルを付けると、日付やお題とともに1枚の画像として保存され、その場で参加者に共有できます。
その場・その時・その人たちでしか生まれない一枚を通して、一期一会の出会いを目に見える形に残します。

また、言葉を交わさなくても一緒に手を動かせるため、初対面の人同士のアイスブレイクや、描いた絵をもとに会話を弾ませるきっかけとしても活用できます。

### 特長
#### 1. 直感的な操作だけで、誰でもすぐに描ける
操作はタップ・スワイプ・振るの3つだけです。タップすると波紋のような円が、スワイプすると線が描かれ、端末を振ると、描いた線が水彩のようににじんで揺らぎます。さらに、画面に触れるたびに音が鳴るため、「上手に描こう」と考えるよりも先に、「音を鳴らしてみたい」という気持ちで自然と手が動きます。ペンや筆の使い方を覚える必要がなく、絵が苦手な人でも思うままに手を動かすだけで作品作りに参加できます。

#### 2. 1人1色で、みんなの色を重ねて1枚の絵に
参加者にはそれぞれ1色が割り当てられ、1台の端末を「次の人へ」と手渡しながら、順番に色を重ねていきます。色がその人自身を表すため、完成した絵を見れば、誰がどこに想いを込めたのかがわかります。

#### 3. お題で迷わず描き始められる
「今の気分を線と形で」のような、正解のない抽象的なお題を用意しています。何を描くか考え込む必要がなく、感じたままに描き始められます。

#### 4. 寄せ書きの署名とタイトルで、出会いを形に残す
描き終えたら、参加者一人ひとりが作品の上に自分の色で署名を書き込みます。寄せ書きのように名前が添えられた作品にタイトルを付けると、日付やお題とともに1枚の画像として保存され、その場で全員に共有できます。

### 解決出来ること
* 一期一会の出会いを、写真とは違う「思い出の形」として残せる
  * 誰と、どんな想いで同じ時間を過ごしたのかが、色と署名とともに1枚の絵に刻まれます。
* 絵が苦手な人でも、共同での作品作りに気軽に参加できる
  * 直感的でシンプルな操作だけで描けるうえ、画面に触れるたびに音が鳴るため、「絵を描く」という意識よりも「音を鳴らして遊ぶ」感覚で手を動かせます。上手い下手を気にせず、誰もが作り手になれます。
* 初対面の人同士でも、言葉に頼らず一緒の時間を楽しめる
  * 一緒に手を動かすこと自体が会話のきっかけとなり、アイスブレイクとしても活用できます。

### 今後の展望
* **数年後に作品を見返すための仕組みを作る**
  * 『OMOIRO』が目指すのは、出会いの記憶を「10年後にも残せる」形にすることです。しかし、保存した画像は時間とともに端末の中に埋もれてしまい、見返されないまま忘れられてしまうかもしれません。そこで、作品を保存した日から1年後や数年後に「あの日の絵」を届ける、タイムカプセルのような機能を追加したいと考えています。また、作品に残っている線のデータを使い、誰がどの順番で色を重ねていったのかを再生できるようにすることで、完成した絵だけでなく、描いていた時間そのものを思い出せるようにしたいです。
* **カラーバリエーションを増やす**
  * 現在は4種類の色のセットからランダムで選ばれますが、パステルカラーやビビッドカラーなど、色のテーマを最初に選べるようにしたいと考えています。イベントの雰囲気や季節、その場のメンバーに合った色を選べるようになれば、作品がより「その日らしい」1枚になるからです。
* **ボタンの数を減らし、もっと直感的に**
  * 現在は「お題」「次の人へ」「完成」など複数のボタンがあり、初めて使う人が迷ってしまう場面があります。ジェスチャーや画面の流れの中で自然に次の操作へ進めるようにし、説明がなくても誰もが使える形を目指します。
* **スワイプ中も音が変化するようにする**
  * 現在は画面に触れた瞬間に音が鳴る仕組みですが、指を動かしている間も、位置や速さに合わせて音の高さや大きさが変わるようにしたいと考えています。線を描くことと音を奏でることが一体になれば、「音を聞くために描く」体験がより豊かになり、描くことへのハードルをさらに下げられるからです。
* **アプリケーションにする**
  * 現在はWebブラウザで動作していますが、アプリ化することで、作品を見返すための通知を届けたり、端末の中に作品のアルバムを作ったりできるようになります。また、加速度センサーや音の再生をより安定して扱えるようになり、操作の気持ちよさも高められます。
* **背景に好きな画像を入れられるようにする**
  * プリクラのように、その日の集合写真や会場の写真を背景に差し込めるようにしたいと考えています。写真が残してくれる「その場にいた」という記録と、絵が残してくれる「一緒に過ごした時間の想い」を1枚に重ねることで、見返したときに、より鮮明にあの日を思い出せるようになるからです。
* **声で描けるようにする**
  * 声の大きさや高さに合わせて、キャンバスが振動したように線が揺れる機能を加えたいと考えています。笑い声や歓声といった、その場の音そのものが絵に刻まれることで、描いた人たちの空気感まで作品に残せるようになるからです。

### 注力したこと（こだわり等）
* **誰でも、迷わず、すぐに描き始められる操作**
  * 制作のハードルを下げるため、操作をタップ・スワイプ・振るの3つだけに絞りました。色やペンを選ぶメニューはあえて用意せず、画面に触れた瞬間から描き始められるようにしています。また、端末を振る操作では、手に持っているだけ・少し傾けただけで反応してしまわないよう、加速度の小さな変化を無視するしきい値を設け、振ったときだけ気持ちよく反応するよう何度も調整しました。
* **1人1色と、1台を手渡しで回す体験**
  * 色を自由に選べるようにするのではなく、1人1色に固定しました。色がその人自身を表すことで、完成した絵の中に一人ひとりの存在が残ります。また、あえて1台の端末を順番に回す形にしたのは、「次の人へ」と手渡すその瞬間にも、自然とやりとりや笑顔が生まれると考えたからです。
* **水彩のようににじむ表現**
  * 線は3つの層に分けて描き、外側をぼかすことで、水彩や墨がにじんだような柔らかい見た目にしています。端末を振ると、揺れの強さに合わせて線が波打ち、にじみが広がって色同士が溶け合います。揺れが収まると、ゆっくりと元の線に戻っていくよう、変化の速さにもこだわりました。
* **音で、「描きたくなる」きっかけをつくる**
  * 絵に苦手意識を持つ人にとって、真っ白なキャンバスに最初の一本を引くことは、思った以上に勇気がいるものです。そこで、画面に触れるたびに音が鳴る仕組みを取り入れました。「何を描こう」「上手く描けるだろうか」と考える前に、「音を聞いてみたい」という好奇心が先に立つことで、描くことへのためらいが自然とほどけていきます。音を鳴らすために触れた一回が線になり、線が重なって絵になっていく。描くことそのものを目的にしなくても、気づけば作品作りに参加している、そんな体験を目指しました。
  * 触れている指の本数によって音の高さが変わるため、1本指から2本指、3本指と試すうちに、音の違いを楽しみながら描き方の幅も広がっていきます。また、スマートフォンのブラウザでは最初の操作で音が鳴らないことがあるため、指を離したタイミングで音を鳴らせる状態にするなど、起動直後の最初の一回から音が楽しめるよう工夫しました。
* **作品を汚さない「寄せ書き」の署名**
  * 署名は、別の画面ではなく作品の上に直接書き込めるようにしました。署名の線は作品の線とは別のデータとして扱い、にじみや揺れがかからない細い線で描くことで、絵の雰囲気を残しながら名前をはっきり読めるようにしています。署名中は揺れやセンサーを止め、端末を手渡しても作品が崩れないようにしました。
* **見返したときに、意味が伝わる1枚に**
  * 保存する画像には、作品と署名に加えて、タイトル・日付・お題を書き添えています。何年か経って見返したときにも、「いつ、どんなお題で、誰と描いたのか」がひと目でわかるようにしたかったからです。

### 独自技術
#### ハッカソンで開発した独自機能・技術
* **端末の揺れに反応して「にじむ」インク表現**
  * 線を「外側のにじみ・中間・中心」の3層に分けて描き、外側をぼかすことで、水彩や墨のような柔らかい線を表現しています。
  * スマートフォンやタブレットの加速度センサーの値を読み取り、端末を振ると揺れの強さに合わせて線が波打ち、ぼかしの量や幅が広がって色同士がにじみ合います。揺れが収まると、ゆっくりと元の線に戻ります。
  * 手に持っているだけ・少し傾けただけで反応しないよう、加速度の小さな変化を無視するしきい値を設け、振ったときだけ気持ちよく反応するよう調整しました。
  * 加速度センサーはHTTPS環境でしか利用できないため、PythonのFastAPIでサーバーを立ち上げ、HTTPSで配信してスマートフォンやタブレットから動作確認できるようにしました。
* **1人1色の交代制による共同制作**
  * 「次の人へ」ボタンで描き手を交代するたびに色が切り替わり、1台の端末を手渡しながら、一人ひとりの色を1枚の絵に重ねていけます。色のセットは起動のたびにランダムで選ばれ、その時にしか作れない作品になります。
* **作品の上に直接書き込む「寄せ書き」の署名と、画像の書き出し**
  * 署名の線は作品の線とは別のデータとして管理し、にじみや揺れがかからない細い線に縁取りを付けて描くことで、絵の上でも名前がはっきり読めるようにしています。
  * 保存時には、背景・作品・署名に加えて、タイトル・日付・お題を1枚の画像に合成します。スマートフォンでは共有メニュー（Web Share API）から、その場で参加者に送ることができます。
* **起動直後から鳴る、指の本数に応じた音**
  * 触れている指の本数によって音の高さが変わり、倍音とリミッターを使って、音割れさせずに聞き取りやすい音にしています。
  * スマートフォンのブラウザでは最初の操作で音が鳴らない制限があるため、指を離したタイミングで音を鳴らせる状態にし、鳴らせなかった最初の音を後から鳴らす仕組みを作りました。
* **Pythonによる線の補正処理**
  * 描いた線をChaikin曲線でなめらかにし、点の間隔をそろえたうえで、マーブル模様のようなゆらぎを加える補正処理をサーバー側で実装しました。
