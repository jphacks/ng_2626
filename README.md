# 『OMOIRO』

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要
複数人で1台の端末を順番に操作し、1枚の絵画を共同制作するプロダクトです。
『OMOIRO』は、「思い出」と「色」を掛け合わせ、参加者の想いを色彩と楽しさで彩り、特別な思い出として残すことを表現しました。

### 背景(製品開発のきっかけ、課題等)
楽しかったイベントや集まりの後に撮影する集合写真は、単なる事実の記録にとどまりがちです。そのため、時間が経って写真を見返したときに、具体的にどのような会話や出来事があったのか、誰とどのような時間を共有したのかといった「その場の空気感や思い出」を十分に思い出せないという課題があります。また初対面の人同士では、何について話すか必要以上に悩んでしまい会話の最初の一歩を踏み出すことが難しく、打ち解けるためのきっかけが作りづらいです。
そこで、絵が苦手な人でも気軽に参加でき、当時の雰囲気を感じることができる思い出の記録を一枚の絵画として生み出せるプロダクトを考えました。

### 製品説明（具体的な製品の説明）
『OMOIRO』は、1台のスマートフォンやタブレットを複数人で順番にタップ・スワイプ・振るといった直感的な操作で動かし、1枚の絵画を作成するプロダクトです。
複数人で描くことで、その場・その時・その人たちでしか生まれない一枚を作り、一期一会の出会いを目に見える形に残します。
また、描いた絵をもとに自分を知ってもらったり、会話を弾ませたりと、初対面の人同士のアイスブレイクとしても活用できます。
直観的な体験を形として残せます．

### 特長
#### 1. 直感的な操作で誰でも描ける
タップ・スワイプ・振るといった直感的な操作だけでart作品を作成でき、絵が苦手な人でも制作に参加しやすくなっています。

#### 2. お題で迷わず描き始められる
思考を介さずに描き始められる抽象的なお題を用意し、描き始めのハードルを下げます。

#### 3. 署名とタイトルで出会いを形に残す
作品にサインを載せることで、誰と描いたものなのかがわかります。
さらに、形になった思い出にタイトルとして名前を与えることができます。
そして，みんなで絵を描くという動作を通して10年後も形と体験を残すことができます

### 解決出来ること
* この瞬間の出会いを新しい「思い出の形」として残し、いつでも鮮明に思い出せるようにする
* 絵が苦手な人でも、作品作りに積極的に参加できる
* 初対面の人同士の会話の一歩目をサポートする

### 今後の展望
* カラーバリエーションを増やす ・・・ パステルカラーやビビッドカラーなど色のテーマを最初に選択できるようにする
* ボタンの数を減らす（もっと直感的に！）
* アプリケーションにする
* 背景を任意の画像を差し込めるように（プリクラのように）する
* 声の入力によってキャンバスを振動させたような描画する機能を加える
* 5年後，10年後も思い出として残るように「1年前こんなことがありました」などお知らせ，通知を出す

### 注力したこと（こだわり等）
* 制作のハードルを下げるため、直感的な操作にこだわりました
